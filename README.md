# 宁夏兰星天然气 · Home Assistant 集成

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/integration)

通过[微信服务号/小程序「宁夏兰星天然气」](https://www.lxtrq.com/)的后端接口，在 Home Assistant 中查询燃气账户余额及（可选）远传表实时余量。

## 功能

- 用户编码 + 用户名称 + 预留手机号三项即可查询，无需密码、无需扫码
- 手机号精确过滤，避免同名账户串户
- 名下每个燃气账户生成一台设备，含：
  - 账户余额（元）
  - 剩余气量（m³，可选，需 OpenID）
  - 累计用气（m³，可选，需 OpenID）
  - 上次结算时间（可选，需 OpenID）

## 安装

### 方式一：HACS（推荐）

1. HACS → 集成 → 右上角菜单 → 自定义存储库
2. 添加本仓库地址，类别选「集成」
3. 搜索「宁夏兰星天然气」并安装
4. 重启 Home Assistant

[![添加到 HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=YXWHome&repository=ha-lanxing-gas&category=integration)

### 方式二：手动安装

将 `custom_components/lanxing_gas` 目录复制到 HA 配置目录的 `custom_components/` 下，重启 Home Assistant。

## 配置

设置 → 设备与服务 → 添加集成 → 搜索「宁夏兰星天然气」。

| 字段 | 必填 | 说明 |
|------|------|------|
| 用户编码 | 是 | 12 位用户编码，或小程序/服务号显示的用户编号（如 <你的用户编码>）|
| 用户名称 | 是 | 户主姓名（如 <你的姓名>）|
| 预留手机号 | 是 | 燃气公司登记的手机号，用于精确锁定本人账户，避免同名串户 |
| OpenID | 否 | 服务号 OpenID（`<Your OpenID>`）；**填写后出现**实时余量/累计用气/结算时间三个传感器 |

### 为什么手机号必填

「用户编码 + 用户名称」可能匹配到多个同名账户（实测某姓名下有 7 个账户）。查询接口本身不支持手机号参数，本集成会在本地用各账户的预留手机号逐一比对，只保留与所填手机号一致的账户，杜绝串户。

### 关于 OpenID（可选）

实时远传表数据（剩余方数 / 累计用气 / 上次结算）位于需鉴权的接口之后，必须提供微信为该账户生成的 OpenID。获取方式：

- 安卓手机安装 HTTPCanary / 小黄鸟，抓小程序或服务号 H5 的请求，从登录响应的 JSON 中取 `openid` 字段
- 或使用 Charles 抓手机流量（手机 WiFi 代理到电脑 + 安装 CA 证书）

> 注意：微信 OpenID 按应用隔离，服务号、小程序、H5 授权拿到的 OpenID 不通用，请使用与你日常查询一致的那一个。

不填 OpenID 时，集成仍可正常显示账户余额等基础信息。

### 不填 OpenID 时能看到什么（重要）

只填前三项就能正常工作，会显示：

- 账户余额（元）：预付费 IC 卡账户显示余额；**远传表 / 后付费账户此值固定为 0.00，属正常现象**，不是故障
- 传感器属性里可查看：用户编号、户主、地址、表号、电话、表类型、最近购气量、最近购气日期、远传累计购气

只有下面三个实时字段依赖 OpenID，未填时显示"未知"：

- 剩余气量（方）
- 累计用气（方）
- 上次结算时间

这三个是远传表的实时抄表数据，燃气公司的接口强制要求 OpenID 鉴权，没有其他获取途径。若无法获取 OpenID，集成的其余功能完全可用，"未知"不影响账户余额和购气记录的读取。

## 支持的设备与实体

每个匹配的燃气账户会创建一台设备（型号「远传表-NB」），包含：

| 实体 | 设备类 | 单位 | 说明 |
|------|--------|------|------|
| 账户余额 | MONETARY | 元 | 账户当前余额 |
| 剩余气量 | VOLUME_STORAGE | m³ | 需 OpenID |
| 累计用气 | GAS | m³ | 需 OpenID |
| 上次结算 | TIMESTAMP | — | 需 OpenID |

实体的属性中包含：用户编号、户主、地址、表号、电话。

## 轮询

默认每 10 分钟轮询一次，可在集成的「重新配置 → 高级设置」中调整（1–1440 分钟）。

## 合规声明

本集成仅用于查询您本人名下的燃气账户。请勿用于他人账户，也不要设置过短的轮询间隔以免对燃气公司服务器造成压力。
